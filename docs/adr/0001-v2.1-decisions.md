# ADR-0001：企业级路线图 v2.1 的 14 项决策正式补录

- 状态：Accepted · 日期：2026-07-16 · 决策人：维护者（WayneStr）
- 背景：ROADMAP v2 经 14 项决策门裁决 + deep-reasoner/Codex 双盲对抗评审（原文 `docs/reviews/`）后定稿 v2.1。裁决过程在主会话以选择题完成，此处补录为正式 ADR。完整表见 ROADMAP §9。

| # | 决策 | 裁决 | 关键理由 |
|---|------|------|---------|
| 1 | 许可证 | Apache 2.0 | 专利授权，企业采用友好 |
| 2 | Python | 3.11–3.13 | 不背 3.10 兼容包袱 |
| 3 | PyPI 包名 | `bellwether-agent` | `bellwether` 已被占用（已核查）；CLI 命令不变 |
| 4 | 插件密钥 | env 为主 + keyring 可选 | 永不明文落盘/入日志 |
| 5 | LLM 定价表 | 内置 + 用户可覆盖 | 版本随发布更新，本地可校正 |
| 6 | 异步范围 | Provider 协议全面 async | 一步到位避免二次返工；同步库 to_thread 包装 |
| 7 | 美股专业源 | M5 开工前专项对比（Polygon vs FMP） | 避免凭印象拍板 |
| 8 | 电话会纪要 | 不内置，插件生态期望 | 免费源面过窄 |
| 9 | 黄金集规模 | 30 标的 × 3 市场起步 | 可信度与成本均衡；时点维度靠 A0 日历积累 |
| 10 | 公开基准姿态 | 只对比钉死的「裸 LLM+搜索」基线 | 可复现、不树敌；点名对比不可持续公平 |
| 11 | MCP 时机 | M5 随 GA（过 E5 安全门禁） | 与 tool 架构契合、生态收益早 |
| 12 | 默认档位 | `analyze` 单 agent / `--deep` 全编排 | 控制日常成本；编排扩张由受控实验决定 |
| 13 | 战略承诺（评审后） | 重述为「最可审计的开源 US/CN/HK 股票研究 agent」；「全球顶尖」为内部北极星；基准免费/专业两档披露 | 承诺必须与证据方式匹配（两评审共识） |
| 14 | v1.0 砍减（评审后） | 温和版：B4/A8/A7b→v1.1，OTel→可选，PDF→stretch，文档英文为主，TCK 最小化；保留 B5/B6 | 保住用户可见的分析深度，砍工程边缘税 |

后果：以上为既定输入，任何 AI/贡献者不得在实施中重开辩论；修改须新 ADR + 用户批准。
