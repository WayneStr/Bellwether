# ADR-0005：数据许可审计（E3）采纳

- 状态：Accepted · 日期：2026-07-17 · 决策人：Fable（主编排）验收 deep-reasoner 审计产出
- 背景：ROADMAP M1 的 E3 数据许可审计完成，产出 `docs/data-licensing.md`（查证真实条款，19 个来源 URL，审计日 2026-07-17）。本 ADR 采纳其结论并触发下游变更。

## 采纳的三个书面结论（工程尽调口径，非法律意见；商业化/公开数据资产/收到权利主张时须人工法务复核）
- **结论 A**：本地私有快照/cassette **不构成再分发**——禁止条款（Yahoo §2(h)、东财第八/十条、新浪 8.4）均以「向第三方提供」为要件，本地留存无第三方接收。采集行为的 ToS 灰区风险**独立存在**，以限流/低频/个人研究姿态持续管理（D2/D4 限流器为持续义务，非一次性）。
- **结论 B**：加密云备份**允许，附四条件**（客户端加密 / 仅本人可访问 / 仅作灾备 / 遵守云商 ToS）——**ADR-0004 云备份开关：开**。未来多维护者共享备份即构成向第三方提供，须重开审计。
- **结论 C**：公开红线清单生效——原始响应 / cassette 原文（含密文形态）/ 新闻全文 / GICS / 批量原始数据表 / 专业源数据**绝不入公开仓库**；公开报告仅派生数字 + 短摘录 + 署名，不附可解析原始数据附件。

## 触发的下游变更
1. **license_tag 词表生效**（data-licensing.md §4，替换 RFC-000 §1/§9 占位）：
   - 黄金集快照与 C2a cassette（Yahoo/东财/新浪/legulegu）= `private-ok-backup-ok`
   - A6 专业源 = `plugin-user-licensed`（数据禁入共享资产，基准仅发分数）
   - 预留 `public-ok`（EDGAR，A7a 复核）/ `private-only` / `derived-only`
2. **`snapshot.py` 的 `LICENSE_TAG`** 常量：占位 → `private-ok-backup-ok`（新 run 生效）。
3. **GICS 不引入**；行业分类用 Yahoo 词表或申万/中证公开层级，标注「非官方 GICS」（A5 落地）。
4. README / 插件文档采用 data-licensing.md §5/§6 的提示文案与许可移交声明（F1/A2 落地）。

## 后果
